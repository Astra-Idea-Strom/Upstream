# 2026-09-19 — Upstream client: production-grade visual flow pass

## Brief
Keep the existing visual theme (brand purple + coral, glassmorphism, Outfit /
Plus Jakarta Sans / Playfair, rounded-3xl) **unchanged**. Make the overall
flow/interface read as production-grade, benchmarked against Replit / Lovable /
Bolt. Success criterion = consistency and neatness.

## Canonical flow model (the backbone of the whole pass)
- `apps/client/src/lib/steps.ts` — the one step definition + `getFlowProgress(flags)`.
- `apps/client/src/hooks/useFlowProgress.ts` — the hook every surface consumes.
  Before this, three separate surfaces each counted a different subset of the
  five flags and disagreed ("0/5 Active" vs "0/5 Complete" vs "2/5 Deliverables
  Materialized"). Progress is now derived in exactly one place.
- `apps/client/src/lib/dom.ts` — `stepCardId(key)`, `KIT_CARD_ID`, `scrollToId`.
  `KIT_CARD_ID` must stay stable: it is the html2canvas capture target.
- `apps/client/src/lib/palettes.ts` — the single palette catalogue. There were
  two divergent copies; index 3 applied a palette the user never picked.
- `apps/client/src/hooks/useArmedAction.ts` — two-step confirm for destructive
  actions (top-bar reset, export card "New project").

## Chrome
- `StudioTopBar` is the *only* studio chrome: brand + breadcrumb (left), step
  rail (centre), actions (right), hairline gradient progress along the bottom.
- `AgentWorkspace`'s pane header is a quiet label, not a second app bar. It used
  to say "AUTONOMOUS WORKSPACE CANVAS · 2/5 Deliverables Materialized".
- `StepRail` and `RichText` were fully built but **never imported** — dead code
  that the UI needed. Both are now wired in.

## Card rendering rule
`StepSlot` in `AgentWorkspace`: `pending` (agent generating) → `showChooser`
(user deciding) → `confirmed` artefact. Choosers render only when
`!isAutoPilot && (isActive(key) || reopened)`. This replaced 700–800 ms timers
that unmounted one card before mounting the next, leaving blank canvas windows.

## Copy / voice
- Assistant turns are unboxed prose + avatar; user turns are the only bubbles.
- The `[Autonomous Agent]: …` bracketed prefix is gone from the auto-pilot
  narration — it now matches the manual path's voice.
- One completion message: `buildCompletionMessage()` in `brandStore.ts`, shared
  by `selectLogoStyle` and `runFullAutonomousPipeline`.
- Confetti fires from exactly one place: `BrandKitExportCard`'s mount effect.

## Flow bugs fixed (all verified by screenshot harness)
1. Free-text after completion wiped the canvas — `sendChatMessage`'s default
   path resets all four `hasConfirmed*` flags. Added a **refinement path** gated
   on `hasConfirmedLogo` that re-tunes only `input.tone` (it previously merged
   the whole `candidateInput`, so "make the tone more luxurious" overwrote the
   Brief card's industry with the chat text).
2. Explicit restart intent (`/^(start (a )?new|new project|reset|start over)/`)
   is handled before the refinement path so it never leaves a finished brand on
   screen.
3. Choosers pre-marked a selection before the user confirmed, because
   `selectedLogoStyle` / `activePaletteIdx` always hold a value for the live
   preview. Highlight is now gated on `hasConfirmedLogo` / `hasConfirmedPalette`.
4. Step 3 had no confirmed artefact — added `cards/TaglineCard.tsx`.
5. Stale "Auto-pilot the remaining steps" chips persisted after completion;
   action options are now suppressed when `progress.isComplete`.
6. Step 5's primary action said "Complete kit" while the other three choosers
   said "Auto-pick" — normalised.

## Toolchain gotcha discovered (cost me a rewrite pass)
**Never issue parallel `Edit` calls against the same file.** They read-modify-write
concurrently and clobber each other: several edits reported success but did not
persist (e.g. `LogoArtworkCard` status, three `brandStore` messages, the
`CanvaEditorToolbar` font-option label). One edit per file per message; then
re-grep to confirm. Symptom to watch for: an edit returns success, but a later
grep still finds the old string.

# 2026-09-19 (later still) — Confirmed-card density pass

## Brief
Issac, on a screenshot of the Brief and Brand Name cards: "too much info to
clutter, too much text and symbols… concentrate on the main things the user
expects, not unnecessary explanations."

## The diagnosis
The **confirmed** cards were spending more pixels on chrome than on content:
a loud purple uppercase pill, a status pill restating the obvious, and one
bordered box with an uppercase label per field. Card 1 held 4 values and
carried 4 uppercase labels, 3 bordered boxes, 2 pills and 1 decorative icon.

## Rules applied (now the house style for confirmed cards)
1. **Drop the status pill on confirmed cards.** "CONFIRMED / SELECTED / LOCKED /
   APPLIED" restate what the canvas already implies. Only *choosing* cards keep a
   status ("Choose one"), because that one is an instruction.
2. **The value is the headline.** `StepBadge` is now a numbered dot + the step
   name in sentence case — it was a purple uppercase pill with a border. The
   header's `border-b` divider is gone too.
3. **One label per row, sentence case.** No `uppercase tracking-wider` micro
   labels. Related values share one quiet meta row (`Audience … Tone …`) instead
   of one bordered box each.
4. **Delete icons that restate their button's text.** The `RefreshCw` on
   "Change name"/"Change tagline"/"Change palette", the `Palette` icon on the
   "Palette" button, the `WandSparkles` on "Logos", the `Smile` on the tone.
5. **Cut explanations of explanations.** "Evokes tactile stoneware mugs and
   single-origin comfort" (a description of the tagline angle) and
   "Scalable vector geometry with calibrated optical balance" are gone. So is
   the "Select a swatch to copy its hex" hint (the hover tooltip covers it).
6. **Never invent content.** The fast path was fabricating a tagline —
   `Crafted with distinction for specialty coffee roastery & micro-café.` — and
   a meaning — `Founder-specified brand identity curated for …`. Now the tagline
   seeds from `getTaglinesForBrand(name)[0]` (Ceramiq → "Warmth in every pour.")
   and the meaning is honestly `Named by you.`

`CardShell.tsx` (StepBadge + header chrome), all six confirmed cards
